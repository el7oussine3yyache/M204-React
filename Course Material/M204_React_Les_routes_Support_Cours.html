03 · Déclarer
Routes et Route

Associer une URL à un composant

Routes regroupe les routes. Chaque Route possède un path et un element.

App.jsxROUTES
import { Routes, Route } from "react-router";
import Accueil from "./pages/Accueil";
import Etudiants from "./pages/Etudiants";
import Contact from "./pages/Contact";

function App() {
  return (
    <Routes>
      <Route path="/" element={<Accueil />} />
      <Route path="/etudiants" element={<Etudiants />} />
      <Route path="/contact" element={<Contact />} />
    </Routes>
  );
}
path
"/etudiants"

L’URL à reconnaître.

element
<Etudiants />

Le composant à afficher.

Modèle mental

URL actuelle → le router cherche une route → il affiche le composant correspondant.

Link et NavLink

Changer de route sans recharger

Pour la navigation interne de l’application, utilisez les composants du router.

À éviter ici
<a href="/etudiants">Étudiants</a>

Peut déclencher un rechargement complet.

À utiliser
<Link to="/etudiants">Étudiants</Link>

Navigation côté client.

Menu.jsxNAVIGATION
import { Link, NavLink } from "react-router";

function Menu() {
  return (
    <nav>
      <Link to="/">Accueil</Link>

      <NavLink
        to="/etudiants"
        className={({ isActive }) =>
          isActive ? "active" : ""
        }
      >
        Étudiants
      </NavLink>
    </nav>
  );
}
Link ou NavLink ?

Link navigue. NavLink navigue et permet de styliser facilement le lien actif.

05 · Paramètres
Route dynamique

Récupérer un id avec useParams

Une partie de l’URL peut devenir une valeur utilisable dans le composant.

/etudiants/12→:id→id = "12"
App.jsxDYNAMIC ROUTE
<Routes>
  <Route path="/etudiants" element={<Etudiants />} />
  <Route path="/etudiants/:id" element={<DetailEtudiant />} />
</Routes>
DetailEtudiant.jsxuseParams
import { useParams } from "react-router";

function DetailEtudiant() {
  const { id } = useParams();

  return (
    <h2>Détail de l’étudiant n° {id}</h2>
  );
}
À retenir

:id est un segment dynamique. useParams() renvoie les paramètres capturés dans l’URL.

06 · Navigation par code
useNavigate

Naviguer après une action

Après un ajout, une connexion ou une validation, on peut changer de route depuis le code.

AjouterEtudiant.jsxuseNavigate
import { useNavigate } from "react-router";

function AjouterEtudiant() {
  const navigate = useNavigate();

  function ajouter() {
    // enregistrer l’étudiant

    navigate("/etudiants");
  }

  return (
    <button onClick={ajouter}>
      Enregistrer
    </button>
  );
}
Enregistrer→ajouter()→navigate()→/etudiants
Règle simple

Pour un lien visible : Link. Pour naviguer après une action dans le code : useNavigate().

Route inexistante

App.jsx404
<Route path="*" element={<NotFound />} />

Le caractère * sert de route de secours lorsque les autres routes ne correspondent pas.

Layout et Outlet

Un layout permet de conserver un menu ou un header commun à plusieurs pages.

App.jsxNESTED ROUTES
<Routes>
  <Route path="/" element={<Layout />}>
    <Route index element={<Accueil />} />
    <Route path="etudiants" element={<Etudiants />} />
    <Route path="contact" element={<Contact />} />
  </Route>
</Routes>
Layout.jsxOUTLET
import { Link, Outlet } from "react-router";

function Layout() {
  return (
    <>
      <nav>
        <Link to="/">Accueil</Link>
        <Link to="/etudiants">Étudiants</Link>
      </nav>

      <main>
        <Outlet />
      </main>
    </>
  );
}
