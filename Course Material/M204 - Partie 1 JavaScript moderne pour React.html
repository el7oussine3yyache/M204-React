Variables

const et let

En JavaScript moderne, on utilise principalement const et let.

const

Utilisé lorsque la variable ne doit pas être réaffectée. 

const nom = "Yassine";

console.log(nom);

// Yassine
Choix recommandé par défaut.
let

Utilisé lorsque la variable doit recevoir une nouvelle valeur. 

let note = 14;

note = 16;

console.log(note);

// 16
À retenir : const → pas de réaffectation • let → réaffectation autorisée
const

Et avec les tableaux et les objets ?

const empêche de réaffecter la variable, mais n’empêche pas de modifier son contenu.

Tableau déclaré avec const 
const notes = [12, 14, 16];

notes[0] = 15;

notes.push(18);

console.log(notes);

// [15, 14, 16, 18]
Objet déclaré avec const 
const etudiant = {
  nom: "Sara",
  note: 14
};

etudiant.note = 17;

console.log(etudiant.note);

// 17
Autorisé 
notes[0] = 15
notes.push(18)
etudiant.note = 17
Non autorisé 
notes = [10, 20]

etudiant = {
  nom: "Ali"
}
À retenir : const protège la référence de la variable, pas le contenu du tableau ou de l’objet.
Fonctions

Les fonctions fléchées

Fonction classique

function calculerTotal(prix, qte) {
  return prix * qte;
}

Fonction fléchée

const calculerTotal = (prix, qte) => {
  return prix * qte;
};
Retour implicite : const carre = n => n * n;
Conditions

L’opérateur ternaire

Une écriture courte de if ... else, très utilisée dans les interfaces React.

Avec if / else 
let resultat;

if (note >= 10) {
  resultat = "Admis";
} else {
  resultat = "Non admis";
}
Avec l’opérateur ternaire 
const resultat =
  note >= 10
    ? "Admis"
    : "Non admis";
Syntaxe 
condition ? valeurSiVrai : valeurSiFaux
À retenir : ? signifie « si vrai » et : signifie « sinon ».

Fonctions callback

1. Callback avec function

Une méthode comme map() reçoit une fonction exécutée pour chaque élément du tableau.

const nouveauEtudiants = etudiants.map(
  function(item, i) {
    return {
      nom: item.nom,
      note: item.note
    };
  }
);
item

l’élément courant du tableau.

i

l’indice courant (facultatif).

return

la valeur placée dans le nouveau tableau.

Premier passage : item = Yassine et i = 0.
Fonctions callback

2. La même callback avec une fonction fléchée

Le fonctionnement ne change pas. Seule la syntaxe de la fonction devient plus moderne.

Avec function
etudiants.map(function(item, i) {
  return {
    nom: item.nom,
    note: item.note
  };
});
Avec fonction fléchée
etudiants.map((item, i) => {
  return {
    nom: item.nom,
    note: item.note
  };
});
Pour commencer : nous gardons les accolades { } et return pour rendre le raisonnement visible.
Tableaux

map() — Transformer

Parcourt tous les éléments et construit un nouveau tableau.

Syntaxe
tableau.map((item, i) => {
  return nouvelleValeur;
});
Exemple
const nouveauEtudiants = etudiants.map((item, i) => {
  return {
    nom: item.nom,
    note: item.note
  };
});
À retenir : map() retourne un nouveau tableau avec autant d’éléments que le tableau d’origine.
Tableaux

filter() — Sélectionner

Garde uniquement les éléments pour lesquels la callback retourne true.

Syntaxe
tableau.filter((item, i) => {
  return condition;
});
Exemple : étudiants admis
const admis = etudiants.filter((item, i) => {
  return item.note >= 10;
});
→ Yassine, Youssef, Abderrahmane, Ghita
Sara n’est pas conservée car sa note est 9.
Tableaux

find() — Trouver un élément

Retourne le premier élément qui respecte la condition.

Syntaxe
tableau.find((item, i) => {
  return condition;
});
Exemple : id = 3
const etudiant = etudiants.find((item, i) => {
  return item.id === 3;
});
→ { id: 3, nom: "Abderrahmane", note: 17 }
Tableaux

reduce() — Accumuler / Calculer

Combine les éléments du tableau pour obtenir une valeur finale.

Syntaxe
tableau.reduce((acc, item) => {
  return calcul;
}, valeurInitiale);
Somme des notes
const total = etudiants.reduce((somme, item) => {
  return somme + item.note;
}, 0);

// 74
0 + 14 → 14
+16 → 30
+17 → 47
+18 → 65
+9 → 74
Méthodes de tableaux

Combiner plusieurs méthodes

Le résultat de filter() est un tableau : on peut donc appliquer map() juste après.

1. filter() → garder les admis
2. map() → récupérer leurs noms
const nomsAdmis = etudiants
  .filter((item, i) => {
    return item.note >= 10;
  })
  .map((item, i) => {
    return item.nom;
  });

// ["Yassine", "Youssef", "Abderrahmane", "Ghita"]

Étape 1 · Modification

Modifier un objet avec spread

Avant de modifier un étudiant dans le tableau, voyons comment créer une copie modifiée d’un objet.

Objet original
const etudiant = {
  id: 2,
  nom: "Youssef",
  note: 16
};
Nouvel objet
const etudiantModifie = {
  ...etudiant,
  note: 18
};
...etudiant copie les propriétés, puis note: 18 remplace uniquement la note.
Étape 2 · Modification

Mettre à jour la liste avec map()

Nous voulons changer la note de Youssef (id = 2) de 16 à 18.

const nouveauxEtudiants = etudiants.map((item, i) => {

  if (item.id === 2) {
    return {
      ...item,
      note: 18
    };
  }

  return item;
});
Pour chaque item
id === 2 ?
Oui → retourner une copie modifiée.
Non → retourner l’objet original.
Étape 3 · Modification

La même modification avec le ternaire

Une fois le raisonnement compris, le if peut être raccourci avec l’opérateur ternaire.

Version avec if
etudiants.map((item, i) => {
  if (item.id === 2) {
    return { ...item, note: 18 };
  }
  return item;
});
Version avec ternaire
const nouveauxEtudiants = etudiants.map((item, i) => {
  return item.id === 2
    ? { ...item, note: 18 }
    : item;
});
map + condition + spread → nouveau tableau mis à jour
Suppression

Supprimer avec filter()

Nous voulons supprimer Sara dont l’identifiant vaut 5.

Code
const nouveauxEtudiants = etudiants.filter((item, i) => {
  return item.id !== 5;
});
Comment le lire ?

Garder tous les étudiants dont l’identifiant est différent de 5.

Sara (id = 5) n’est donc pas conservée.
Important : filter() produit lui aussi un nouveau tableau.

Classes et objets

Une classe sert de modèle pour créer plusieurs objets possédant la même structure et les mêmes comportements.

Classe

Le modèle qui définit les propriétés et les méthodes.

Etudiant

Classes

Déclarer une classe

Le mot-clé class permet de définir un modèle d’objet. 

class Etudiant {

  constructor(nom, note) {
    this.nom = nom;
    this.note = note;

}
class Etudiant

déclare la classe.

constructor()

initialise les nouveaux objets.

this

désigne l’objet courant.

Objets

Créer des objets avec new

Le mot-clé new crée une nouvelle instance de la classe. 

const yassine = new Etudiant("Yassine", 14);

const ghita = new Etudiant("Ghita", 18);
Objet yassine
yassine.nom

yassine.note

Objet ghita

ghita.note
// 17
À retenir : une même classe peut servir à créer plusieurs objets différents.
Classes

Ajouter des méthodes

Une méthode représente un comportement que les objets peuvent exécuter. 

class Etudiant {

  constructor(nom, note) {
    this.nom = nom;
    this.note = note;
  }

  estAdmis() {
    return this.note >= 10;
  }

}
Utilisation 
const yassine =
  new Etudiant(
    "Sara",
    15
  );

yassine.estAdmis();

// true
Propriétés → données de l’objet • Méthodes → comportements de l’objet
Héritage

Réutiliser une classe avec extends

L’héritage permet de créer une nouvelle classe à partir d’une classe existante.

Classe parent 
class Personne {

  constructor(nom) {
    this.nom = nom;
  }

  sePresenter() {
    return `Je suis ${this.nom}`;
  }

}
Classe enfant 
class Etudiant
  extends Personne {

  constructor(nom, note) {

    super(nom);

    this.note = note;
  }

}
extends → hériter d’une classe • super() → appeler le constructeur de la classe parent

Pourquoi utiliser des modules ?

Les modules permettent de découper une application en plusieurs fichiers ayant chacun une responsabilité précise.

Sans modules

Un module = un fichier JavaScript qui peut exporter et importer des éléments.
Modules ES6

export — rendre un élément disponible

Un élément déclaré dans un fichier reste local à ce fichier, sauf si on l’exporte.

export const trouverEtudiant = (id) => {
